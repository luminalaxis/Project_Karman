# FINAL SUMMARY — fsk-lapsim

> 이 파일은 핵심 Phase (P0–P10) 완료 시점 기준이며, 확장 목표 (E1–E5) 결과는 아래 "확장 기능" 절에 추가된다.

## 1. 구현된 기능

- **차량 모델 두 단계**: 모델 A (점질량, 검증 기준선), 모델 B (축 단위 준정상: 공력 밸런스·종/횡 하중이동·LLTD·
  하중민감 타이어·축별 횡력 요구·LSD/오픈 디프·이상/고정 제동배분). 코너 한계는 "속도 유지 가능" 기준 (D-08).
- **GGV 표 + QSS 솔버**: 제약별 표 + 출력 한계 닫힌 식 (보간 오차 0.0085 m/s²), Heun 전진/후진 적분, 플라잉 랩 반복,
  랩당 약 0.05 s.
- **트랙**: 직선/원호/슬라럼 세그먼트, 규칙 기반 시드 고정 생성기 (오토크로스 열린 코스, 엔듀런스 Dubins 폐합),
  손 설계 템플릿 3 개, (x, y) CSV 임포트 (스플라인 평활화, σ 파라미터), 미러, 규칙 검사. 저장소에 있던 FSK 2026 엔듀런스
  중심선을 참고 트랙으로 포함.
- **파워트레인·에너지**: 토크/출력/회전수 한계, 정지 출발 처리, 회생 (후축 분담, 20 kW), 어큐뮬레이터 에너지, 모터 운전점 히스토그램.
- **공력**: 부품 합성 (ClA, CdA, 압력중심, 항력 높이, 질량, 질량중심 → 전체 공력·총질량·CG), 2D→3D 변환 헬퍼, 리어윙 후보 CSV,
  프론트윙 재트림 옵션.
- **이벤트 4 종**: 가속 75 m, 스키드패드 (정상선회 해석), 오토크로스, 엔듀런스 (첫 랩 정지 출발 + 플라잉 랩, 출력 제한 옵션).
- **분석**: 민감도·등가 환산표·실측 우선순위, ClA×CdA 스윕, 후보 비교 (순위·Δ), 밸런스 최적화, 능동 공력 (DRS).
- **출력**: typer CLI 11 개 명령, 단일 HTML 리포트 (한국어, 그래프 내장, 가정 목록, 모델 한계), CSV 채널.
- **문서**: README, MODEL (수식·검증표), ASSUMPTIONS, DECISIONS (D-01–D-16), PROGRESS.

## 5. 모델의 한계와 결과를 신뢰할 수 없는 영역

1. **절대 랩타임**: 타이어 μ0·k 가 가정값이고 영향이 가장 크다 (σ 하나에 오토크로스 ±1.8 s). 실측 전에는 절대값을 믿지 말 것.
2. **주행선 = 트랙 기하**: 레이싱 라인 최적화가 없어 헤어핀·슬라럼이 보수적. 실제 FSK 2026 중심선은 최소 반경 2.5 m 로
   합성 트랙보다 훨씬 타이트하다 → 트랙 형태에 따라 공력 민감도가 달라진다 (저속 트랙일수록 ClA 가치 감소).
3. **준정상**: 요 관성·과도 하중이동 없음 → 빠른 슬라럼·시케인 낙관적. 밸런스 최적점은 두 축 동시 포화점 (실차는 안정성 마진 필요).
4. **2D→3D 변환**: 유효 종횡비·k·e 가정에 따라 후보 간 차이가 커지거나 작아질 수 있다. 다운포스·항력 비가 비슷한 후보끼리의
   순위는 신뢰도가 낮다 (E1 몬테카를로로 역전 확률 확인).
5. **공력 상수**: 차고·피치·요·롤·후류 영향 없음. 리어윙과 디퓨저 상호작용 없음.
6. **에너지**: 최대 성능 주행 가정, 배터리 전압 강하·열 디레이팅·인버터 한계 없음. 효율 상수 0.85 (토크 경로에도 적용 — 보수적).
7. **DRS**: 계수 변화·전환 시간이 가정값, 플랩 전환 중 공력 히스테리시스 없음.

## 6. 다음에 할 일 3 가지

1. **타이어 실효 μ0 와 하중민감도 k 를 실측**한다 — 현 차량으로 스키드패드 (가능하면 밸러스트로 하중을 바꿔 2 회) 를 돌려
   정상선회 ay 로 역산하고 `vehicle.yaml` 에 숫자로 넣는다. 이 두 값이 모든 결과 불확실성의 대부분이다.
2. **실제 ANSYS 2D 결과로 `rear_wing_candidates_DUMMY.csv` 를 대체**하고 (가능하면 대표 1–2 개는 3D CFD 로 `cla_3d_m2`/`cda_3d_m2`
   를 넣어 변환 계수를 보정), `fsk-lapsim compare` 와 `--retrim-front` 비교, 몬테카를로 순위 역전 확률을 확인한다.
3. **FSK 규정 수치 (트랙 범위, 출력 상한, 엔듀런스 거리, 스키드패드 치수) 와 팩 용량을 확정**해 `events.yaml`·트랙 규칙·
   `endurance_max_power_w` 에 반영하고, 실제 코스 데이터 (FSK 2026 중심선, GPS 로그) 로 기본 트랙을 바꾼다.
