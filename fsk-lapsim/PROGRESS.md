# PROGRESS — 진행 상황 (세션 인계용)

## 이어받는 방법
```bash
cd fsk-lapsim
pip install -e ".[dev]"
python -m pytest -q --cov=fsk_lapsim     # 전체 테스트 + 커버리지
ruff check src tests
```
- 지시서: 저장소 루트 대화의 "FSK 랩타임 시뮬레이터 + 에어로 민감도 분석 도구 — 무인 개발 지시서".
- 결정 기록: DECISIONS.md, 가정값: ASSUMPTIONS.md, 수식: MODEL.md.
- 각 Phase 끝에 테스트 통과 → 커밋 → 이 파일 갱신.

## 완료 내용
### P0
- `pyproject.toml` (패키지 `fsk_lapsim`, CLI 엔트리 `fsk-lapsim`), src 레이아웃.
- pydantic 설정 스키마 `config.py` (모든 수치 = `Param{value, unit, assumed, note}`), 예시 YAML
  (`vehicle.yaml`, `aero_components.yaml`, `events.yaml`), 런타임 데이터클래스 (`Vehicle`, `Tire`, `Aero`, `Powertrain`).
- 부품 합성이 ClA 3.5 / CdA 1.4 / 밸런스 45 % 를 정확히 재현하도록 배치.

### P1
- `track.py`: `Straight`/`Arc`/`Slalom`(κ = κmax·cos, Struve/Bessel 로 정확한 끝점) 세그먼트, `SegmentTrack`, `SampledTrack`,
  `track_from_xy` (splprep 평활화, σ 파라미터, 호길이 재표본, 곡률), 미러, 등간격 이산화.
- `trackgen.py`: 규칙(`LayoutRules`) 기반 시드 고정 생성기 (오토크로스=열린 코스, 엔듀런스=Dubins CSC 폐합),
  규칙 검사(`check_layout`: 최장 직선, 최소 반경, 자기 간격, 폐합 오차), 직선 2개 길이를 풀어 정확히 폐합하는 `adjust_straights`.
- 트랙 YAML: `autocross_generated`(seed 42, 814 m), `endurance_generated`(seed 7, 918 m), 템플릿 A(709 m)/B(587 m)/C(514 m),
  `fsk2026_endurance`(저장소 실측 기반 중심선 CSV, 843 m, 시계방향, 최소 반경 2.5 m — FS 규정 범위보다 훨씬 타이트).

### P2
- `models.py`: 모델 A(점질량)와 모델 B(축 단위, 하중이동·하중민감도·LLTD·LSD/오픈 디프·이상/고정 제동배분)를 같이 구현.
  한계 정의는 일정 속도 기준 (D-08, 처음의 코스팅 정의에서 수정 — 이유 기록).
- `ggv.py`: (v, θ) 격자 GGV + 순수 파이썬 스칼라 보간, 차량별 lru_cache. `solver.py`: 곡률 한계(이분법), Heun 전진/후진,
  플라잉 랩 반복, `LapResult`. `energy.py`: 구간별 힘·에너지·회생·모터 운전점.
- 검증 1~6 통과: 원 선회 해석해 (상대오차 ~1e-9), 최고속도 (출력·항력 해석해 1e-6, 회전수 제한), 75 m 가속 vs solve_ivp
  (A 2e-5, B 2e-6), 격자 수렴 (ds 0.25→0.125 변화 < 1e-4), 단조성 (출력·μ·CdA·ClA), 미러 대칭 (1e-12).
- 기본 차량(모델 B) 참고값: 가속 4.20 s, 스키드패드 5.10 s, 합성 오토크로스 55.9 s (평균 52 km/h).

### P3
- 모델 B 진단 `ay_max_by_limit` (전륜 횡 / 후륜 횡 / 구동 각각의 한계), 가속 한계의 제약별 분해 `ax_accel_parts`.
- GGV 정확도 개선 (D-14): 최고속도 격자 끝 정렬, 제약별 표 + 출력 한계 닫힌 식. 직접 계산 대비 최대 0.0085 m/s².
- 테스트 7 (밸런스 0 → 전륜 먼저, 1 → 후륜 먼저, 랩타임 내부 최적), 9 (GGV vs 직접), 하중 평형·LLTD·휠 리프트·오픈 디프·
  고정 제동배분·하중민감도·타이어/파워트레인 단위 테스트. 총 84 테스트 통과.
- 관찰: 기본 차량은 저속에서 후륜 구동 한계(항력 상쇄 구동력 + 횡력)가 근소하게 먼저 걸리고 전/후 횡한계가 거의 같다 (균형).

### P4
- 에너지 (`energy.py`): 구간별 v̄² 로 항력·다운포스 정확 평균, 구동/제동 일, 회생(후축 분담 × 모터 토크·20 kW 한계),
  어큐뮬레이터 순 에너지, 출력 시계열, 모터 토크·rpm, 시간가중 운전점 히스토그램.
- 테스트 8: (a) 구동 일 − 제동 일 = ΔKE + 항력 + 구름 (구간 정의, 1e-9) (b) 노드 속도로 시간 적분한 손실과 비교
  (허용 0.5 %, 관측 6e-6). 출력·회생 한계, 회생 on/off, 정지 출발 유한성, 모터 한계 테스트.
- 참고 (가정값 기반): 엔듀런스 합성 루프 1 랩 0.361 kWh (회생 0.050 kWh 포함), FSK 2026 중심선 0.333 kWh/랩.

### P5
- `wing.py`: 2D→3D 헬퍼 (Cl3D = k·Cl2D, Cd3D = Cd2D + Cl3D²/(π e AR_eff), 기본 AR_eff = AR×1.5, k = AR/(AR+2), e = 0.9,
  "대략적 추정" 명시), 후보 CSV 로더 (필수/선택/자유 열, 3D 직접 입력 우선, Cm→x_cp), 부품 교체 → 질량·CG·밸런스 갱신,
  프론트윙 재트림 옵션 (`retrim_front`).
- `data/rear_wing_candidates_DUMMY.csv`: 8 행 (플랩 2×2 조합 + 각도/갭 변형), 파일명·notes 에 DUMMY.
- `analysis/compare.py`: 후보별 이벤트 시간, 기준 대비 Δ, 이벤트별 순위, 엔듀런스 에너지 Δ, 기준 패키지 행.
- DUMMY 결과 (의미 없음, 형식 확인용): 다운포스가 큰 RW06 이 오토크로스·엔듀런스 1위 — 항력 증가보다 다운포스·밸런스 이동
  (뒤로 → 45 % 근처) 효과가 큼. 재트림 옵션을 쓰면 밸런스 효과를 분리할 수 있다.
### P6
- `events.py`: 가속 (75 m 정지 출발), 스키드패드 (정상선회 해석: v²/R = ay_max(v), 좌/우 평균), 오토크로스 (정지/플라잉),
  엔듀런스 (첫 랩 정지 출발 → 플라잉 랩 속도로 연결, 랩 수 = round(22 km / 랩 길이), 에너지 회생 포함/미포함),
  선택적 엔듀런스 출력 제한 (`endurance_max_power_w`, 에너지 관리용), 타당성 경고.
- 기본 차량 (가정값 기반): 가속 4.198 s, 스키드패드 5.098 s (1.41 g), 오토크로스 55.85 s (52.5 km/h),
  엔듀런스 24 랩 1282.5 s, 8.68 kWh (회생 1.19 kWh). 타당성 경고 없음.
- 관찰: 엔듀런스 에너지 8.7 kWh 는 FS EV 어큐뮬레이터 일반 용량(6–8 kWh)보다 크다 → 가정 CdA 1.4·질량 320 kg 영향.
  실제 팩 용량이 정해지면 `endurance_max_power_w` 로 에너지 관리를 시뮬레이션해야 한다.

### P7
- `analysis/sensitivity.py`: 중앙차분 민감도 (지시서 7개 + 우선순위용 7개 추가 파라미터), 표시 단위(0.1 m², 1 kg, 1 cm, 1 %p, 1 kW),
  등가 환산표, "먼저 실측할 파라미터" 순위 (|dt/dp|·σ, σ = `configs/uncertainty.yaml`).
- `analysis/sweep.py`: ClA×CdA 격자 → 오토크로스 시간, 엔듀런스 시간·에너지 + 표시점(현재 차량·후보).
- `analysis/balance_opt.py`: 스캔 + bounded Brent, 목적함수 autocross / endurance_lap / combined, 최적점 축별 한계.
- `analysis/uncertainty.py` + `configs/uncertainty.yaml`: 정규/균등 분포, 클립, 2D→3D 계수 불확실성, 후보별 CFD 오차.
- 결과 (가정값 기반, 오토크로스): ClA +0.1 m² → −0.050 s, CdA +0.1 m² → +0.037 s, +1 kg → +0.031 s,
  CG +1 cm → +0.067 s, μ0 +0.01 → −0.178 s, +1 kW → −0.018 s. 등가: 1 kg ≈ ClA −0.061 m² ≈ CdA +0.083 m².
  밸런스 최적 43.3 % (45 % 대비 −0.020 s, 두 축 동시 포화점 — 실차는 안정성 마진 필요).
- 실측 우선순위 (시간 기준): μ0 > 하중민감도 k > 질량 > ClA > CG 높이 > 밸런스 > CdA > 효율 … (에너지 기준은 μ0·효율·k·CdA 순).

### P8
- `active_aero.py` + `configs/drs.yaml`: 개방 상태 = 리어윙 ClA −65 %, CdA −55 % (가정, 차량 공력에 델타로 적용 → 밸런스 자동 이동),
  전환 시간 0.25 s 선형 보간, 개방 조건 (|ay| < 0.5 g, 최대 가속, v ≥ 자동 교차 속도 78 km/h — D-15), 짧은 구간 생략,
  구간↔재시뮬레이션 반복. 출력: 이벤트별 시간 이득, 랩당 전환 횟수, 개방 비율(거리/시간), 구간별 닫힘 명령 위치·리드(m, s),
  최악 리드(구간 최고속 × T), 에너지 절감, 리드 거리 표.
- 결과 (가정값 기반): 가속 +0.012 s, 오토크로스 +0.033 s (5 구간, 전환 10 회), 엔듀런스 랩 +0.027 s → 총 +0.66 s,
  에너지 −0.045 kWh. 닫힘 명령은 제동 시작 약 7–8 m (0.25 s) 전. 저속 개방 시 오히려 손해 (−0.08 s/랩).
  → 1 kg 이 오토크로스 0.031 s 이므로 DRS 이득은 액추에이터 질량 ~1 kg 과 비슷한 수준 (회전수 제한 140 km/h, 짧은 직선).

### E1
- `analysis/montecarlo.py`: 공통 요인 (차량 가정, 2D→3D 계수) + 후보별 CFD 오차, 오토크로스·엔듀런스 플라잉 랩, 공통난수,
  프로세스 병렬, 재트림 옵션. 분포·P(1위)·평균 순위·P(순위 유지)·쌍별 역전 확률·전체 순위 유지 확률. CLI `montecarlo`,
  리포트 11b 절 (`--mc N`), 그래프 (히스토그램, 순위 확률 막대).
- `apply_component_change` 를 현재 공력에 대한 델타로 변경 (D-18).
- 결과 (가정값, 200 샘플): 기준 차량 오토크로스 p5–p95 = 53.6–58.9 s (σ 1.8 s), 엔듀런스 랩 51.0–56.4 s.
  DUMMY 후보: 밸런스 고정 (재트림) 시 RW06 이 1위일 확률 0.58 (오토크로스) / 0.67 (엔듀런스), 명목 차이 < 20 ms 인 쌍은
  30–45 % 확률로 역전, 전체 순위 유지 확률 3–6 %. 재트림 없이는 밸런스 가정 (σ 3 %p) 이 순위를 크게 흔든다 (최하위 RW08 도 10 % 1위).
  → 실제 후보 비교에서는 밸런스를 맞춘 비교 (`--retrim-front`) 와 함께 볼 것.

### E3
- `thermal.py` + `configs/thermal.yaml`: 모터·인버터·팩 손실 모델, 집중 열모델 (지수 해), 부품별 총 발열·평균/최대·온도·
  필요 열저항, 모터+인버터 함축 효율. CLI `thermal`, 그래프 (온도·손실 추이, 모터 효율 맵), 리포트 10b 절.
