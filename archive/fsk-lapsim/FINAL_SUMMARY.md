# FINAL SUMMARY — fsk-lapsim

핵심 Phase P0–P10 과 확장 목표 E1–E5 를 모두 끝낸 시점의 요약이다. 진행 기록은 PROGRESS.md, 설계 결정 22 건은 DECISIONS.md.

## 1. 구현된 기능

**핵심**
- **차량 모델 두 단계**: 모델 A (점질량, 검증 기준선), 모델 B (축 단위 준정상: 공력 밸런스·종/횡 하중이동·LLTD·하중민감 타이어·
  축별 횡력 요구·LSD/오픈 디프·이상/고정 제동배분). 코너 한계는 "속도 유지 가능" 기준 (D-08).
- **GGV + QSS 솔버**: 제약별 표 + 출력 한계 닫힌 식 (직접 계산 대비 0.0085 m/s²), Heun 전진/후진 적분, 플라잉 랩 반복 (랩당 0.02–0.05 s).
- **트랙**: 직선/원호/슬라럼 세그먼트, 규칙 기반 시드 고정 생성기 (오토크로스 열린 코스, 엔듀런스 Dubins 폐합), 손 설계 템플릿 3 개,
  (x, y) CSV 임포트 (스플라인 평활화), 미러, 규칙 검사. 저장소에 있던 FSK 2026 엔듀런스 중심선을 참고 트랙으로 포함.
- **파워트레인·에너지**: 토크/출력/회전수 한계, 정지 출발 처리, 회생, 어큐뮬레이터 에너지, 모터 운전점 히스토그램.
- **공력**: 부품 합성 (ClA, CdA, 압력중심, 항력 높이, 질량, 질량중심 → 전체 공력·총질량·CG, 현재 공력에 대한 델타 적용),
  2D→3D 변환 헬퍼, 리어윙 후보 CSV, 프론트윙 재트림.
- **이벤트 4 종**: 가속 75 m, 스키드패드 (정상선회 해석), 오토크로스, 엔듀런스 (첫 랩 정지 출발 + 플라잉 랩, 출력 제한 옵션).
- **분석**: 민감도·등가 환산·실측 우선순위, ClA×CdA 스윕, 후보 비교, 밸런스 최적화, 능동 공력 (DRS, 닫힘 명령 리드).
- **출력**: typer CLI 15 개 명령, 단일 HTML 리포트 (한국어, 그래프 16 장 내장, 가정 목록, 모델 한계), CSV.

**확장**
- **E1 몬테카를로**: 차량 가정 + 2D→3D 계수 (후보 공통) + 후보별 CFD 오차, 랩타임 분포, P(1위)·순위 유지·쌍별 역전·전체 순위 유지 확률.
- **E2 GPS**: NMEA (RMC/GGA/VTG) → 랩 분할 → 도플러 진행방향 기반 트랙 재구성 → 실측 vs 시뮬레이션 속도 비교.
- **E3 발열**: 모터·인버터·팩 손실 모델 + 집중 열모델, 필요 열저항.
- **E4 점수 환산**: YAML 공식 (자리표시자) → 시간 차이를 점수 차이로 (민감도·후보 비교 포함).
- **E5 성능**: GGV 빌드 최적화, 스윕·민감도·비교·리포트 병렬화 (리포트 51 → 18 s, 결과 동일).

## 5. 모델의 한계와 결과를 신뢰할 수 없는 영역

1. **절대 랩타임**: 타이어 μ0·k 가 가정값이고 영향이 가장 크다 (σ 하나에 오토크로스 ±1.8 s). 실측 전에는 절대값을 믿지 말 것.
2. **주행선 = 트랙 기하**: 레이싱 라인 최적화가 없어 헤어핀·슬라럼이 보수적. FSK 2026 중심선은 최소 반경 2.5 m 로 합성 트랙보다
   훨씬 타이트하다 → 트랙 형태에 따라 공력 민감도가 달라진다 (저속 트랙일수록 ClA 가치 감소). GPS 로그 트랙 (실제 주행선) 이 더 낫다.
3. **준정상**: 요 관성·과도 하중이동 없음 → 빠른 슬라럼·시케인 낙관적. 밸런스 최적점은 두 축 동시 포화점 (실차는 안정성 마진 필요).
4. **2D→3D 변환**: 유효 종횡비·k·e 가정에 민감. 명목 차이 20 ms 미만 후보 사이의 순위는 신뢰하기 어렵다 (E1).
5. **공력 상수**: 차고·피치·요·롤·후류 영향, 리어윙–디퓨저 상호작용 없음. DRS 계수·전환 시간도 가정값.
6. **에너지·발열**: 최대 성능 주행 가정, 효율 상수 0.85 (토크 경로에도 적용 — 보수적), 배터리 전압 강하·열 디레이팅 없음.
   발열 계수·열저항은 전부 가정값.
7. **GPS**: 1 Hz (NEO-6M 기본값) 로깅은 헤어핀을 놓쳐 시뮬레이션이 7–14 % 빨라진다 → 5–10 Hz 로 설정해야 한다.
8. **점수**: 공식·기준 기록 모두 자리표시자 → 점수 절대값은 의미 없음, 차이의 크기 감각으로만.

   불확실성의 대부분이다.

   계수 보정), `fsk-lapsim compare --retrim-front` 와 `fsk-lapsim montecarlo --retrim-front` 로 순위와 역전 확률을 확인한다.
3. **FSK 규정 수치와 팩 사양을 확정**해 반영한다 — 트랙 범위·출력 상한·엔듀런스 거리·스키드패드 치수 (`events.yaml`, 트랙 규칙),

   현재 가정에서 가장 빠듯한 설계 제약이다.
